# Range-Query Algorithms

## Implementations

- [fenwick_inversions.c](fenwick_inversions.c) — uses a Fenwick tree to count inversions in a sequence.

This directory currently contains one focused example and can be expanded as more range-query and counting algorithms are added.

## Compile an example

From the repository root:

```bash
gcc algorithms/range-queries/fenwick_inversions.c -std=c11 -Wall -Wextra -Wpedantic -o fenwick_inversions
```

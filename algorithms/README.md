# Algorithms

This directory groups algorithm implementations by problem domain.

## Topics

- [Graph algorithms](graphs/README.md) — traversal, shortest paths, spanning trees, matching, connectivity, and flow.
- [Tree algorithms](trees/README.md) — tree traversal, decomposition, ancestor queries, and tree dynamic programming.
- [Dynamic programming](dynamic-programming/README.md) — knapsack variants, subsequences, and optimization problems.
- [String algorithms](strings/README.md) — pattern matching, suffix structures, and substring queries.
- [Range-query algorithms](range-queries/README.md) — inversion counting with a Fenwick tree.

Most files are standalone demonstrations. Check each file for its expected input, assumptions, and compiler requirements before using it.

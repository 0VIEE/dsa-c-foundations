# Dynamic Programming

Examples of optimization and sequence problems commonly solved with dynamic programming or related recurrence-based techniques.

## Implementations

- [bounded_knapsack.c](bounded_knapsack.c) — bounded knapsack
- [coin_change_ways.c](coin_change_ways.c) — counting coin-change combinations
- [kadane_max_subarray.c](kadane_max_subarray.c) — maximum subarray sum
- [knapsack_01.c](knapsack_01.c) — 0/1 knapsack
- [lcs.c](lcs.c) — longest common subsequence
- [lps.c](lps.c) — longest palindromic subsequence
- [max_product_subarray.c](max_product_subarray.c) — maximum product subarray
- [mcm.c](mcm.c) — matrix-chain multiplication
- [subset_sum.c](subset_sum.c) — subset sum

## Compile an example

From the repository root:

```bash
gcc algorithms/dynamic-programming/knapsack_01.c -std=c11 -Wall -Wextra -Wpedantic -o knapsack_01
```

Run `./knapsack_01` on Linux/macOS or `knapsack_01.exe` on Windows. This is an example command; individual programs may have different assumptions.

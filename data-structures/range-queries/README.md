# Range-Query Data Structures

## Implementations

- [fenwick_tree.c](fenwick_tree.c) — Fenwick tree (Binary Indexed Tree)
- [segment_tree_rmq.c](segment_tree_rmq.c) — segment tree for range-minimum queries
- [succinct_bitvector.c](succinct_bitvector.c) — succinct bit-vector experiment

## Compile an example

From the repository root:

```bash
gcc data-structures/range-queries/fenwick_tree.c -std=c11 -Wall -Wextra -Wpedantic -o fenwick_tree
```

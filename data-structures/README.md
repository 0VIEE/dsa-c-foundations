# Data Structures

This directory groups implementations by the kind of data structure being explored.

## Topics

- [Linear structures](linear/README.md) — linked lists, stacks, and queues.
- [Trees](trees/README.md) — binary trees and binary search tree examples.
- [Priority queues](heaps/README.md) — priority-queue example.
- [Range-query structures](range-queries/README.md) — Fenwick trees, segment trees, and bit vectors.
- [Tries](tries/README.md) — prefix-tree autocomplete.

Examples are learning-oriented. Check source comments for input limits, memory assumptions, and supported operations.

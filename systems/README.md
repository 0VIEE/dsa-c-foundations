# Systems Programming

Experiments involving memory allocation, concurrency, and system-oriented data structures.

## Topics

- [Memory](memory/README.md) — allocation, alignment, arenas, and slab/buddy allocators.
- [Concurrency](concurrency/README.md) — lock-free and bounded queue experiments, hazard pointers, and cache-line padding.
- [Advanced experiments](advanced/README.md) — AST dead-code analysis, consistent hashing, and timing wheels.

These examples are educational experiments and are not automatically production-ready. Concurrency and memory-management code deserves careful testing before reuse.
